# Traffic Board v1.6.3

这一版全部围绕「看得见、说得清、放得下」——没有新增采集能力，数据口径与 v1.6.2 完全一致。

## 反馈与回执

- **右键动作全部有回执**：导出 CSV、用 Wireshark 抓这条、断开这条代理连接，成功失败都会说一声
  （导出成功报条数与文件路径；失败区分「文件被占用/无权限」和其他原因，且绝不清空你原来那份 CSV）。
- **提醒改走窗口内可见的通道**：月流量配额、陌生连接提醒以前只发托盘气泡，窗口开着时你根本看不到；
  现在窗口在前台就显示在窗口顶部，收进托盘才退回气泡。
- **提醒条不再比窗口宽**：中文提醒以前会被切掉左右两头（半屏贴靠时尤其明显），现在按真实字宽折行，
  窗口多窄都完整可读，一个字都不丢。
- **陌生连接提醒限流两层**：同一进程每小时最多 1 条、全局每分钟最多 1 条。
  首次启动几十条连接一起「陌生」时只弹一条，连接照常记账。
- **设置页的「新连接提醒」开关真的跨重启生效**（以前构造函数把它写死成开，关掉下次启动又回来）。
- **悬浮速率条的位置会记住**：拖到哪儿，下次启动还在哪儿（以前每次启动都弹回默认位置）。

## 读得懂

- **连接明细「没东西」时会说明为什么**，三种情况各说各话：
  没点过任何软件 → 提示点左侧；选中的软件已退出/本次没采到 → 说明进程结束并让你点别的；
  搜索框过滤到 0 条 → 报出关键词和该进程连接总数，并说明清空搜索框可看全部。
- 空态下右键不会再误伤一条已经不显示的活连接（右键菜单的目标行在空态会被清掉）。
- 帮助页「常见问题」同步补齐以上几条的解释。

## 小屏笔记本

- 窗口最小尺寸从 **885x806 降到 456x510**：1366x720 的笔记本现在能整个放下（以前底部一截永远在屏幕外）。
- 设置页改为页内滚动，长说明文字自动换行；排行里的软件名与流量明细放不下时走省略号，
  完整内容在鼠标悬浮提示里。
- 缩到极限就停在极限上，不会再被布局反撑回去（以前数据一到，窗口会自己变大）。

## 稳定性

- 单实例：第二次双击图标时，正在运行的窗口会被唤到前台并给出可见反馈，不再「点了没反应」。
- 退出路径不再出现收尾崩溃；测试基础设施收口，跑测试不会污染你的历史库与设置。

## 下载与运行

- 解压后运行 `TrafficBoard/TrafficBoard.exe`（绿色目录，无需安装；`_internal` 必须和 exe 放在一起）。
- 数据全部在本机采集与显示，不上传任何内容。
- 已开着旧版的同学：请先完全退出旧实例（托盘图标右键退出）再启动新版，否则新实例只会把旧窗口唤到前台。
