# Traffic Board v1.6.5

这一版磨的是「不用鼠标也能用」：窗口刚打开时键盘站在哪儿、Tab 会不会把你关进表格里、
左边那列页签键盘根本摸不到，以及一次翻页到底要按几次键。
采集能力与数据口径和 v1.6.2 / v1.6.3 / v1.6.4 完全一致，没有新增统计。

## 修掉的四件具体事

- **窗口一打开，第一个回车不再把程序弄"没了"。**
  之前初始焦点落在标题栏的最小化按钮上：按第一下回车收进任务栏，第二下缩进托盘，
  看着像程序闪退了。现在三枚窗口按钮退出键盘（和原生 Windows 程序一致——它们的按钮属于
  非客户区，本来就不参与 Tab）。出路没有被动过：实测窗口句柄仍带 `WS_SYSMENU`、
  系统菜单里 `SC_CLOSE`/`SC_MINIMIZE` 都在，Alt+F4 与 Alt+空格 照常工作。

- **Tab 键不再把你关在连接明细表里。**
  表格是只读的，但它默认把 Tab 当"跳到下一个单元格"：有数据时每按一次 Tab 只在
  第一行的四列里绕圈（实测连按 12 次全留在表内），既到不了别的行也走不出这个控件。
  现在 Tab 回到"下一个控件"的本来语义，行内仍然用 ↑ / ↓ 走。

- **左边的页签终于能用键盘了，而且看得见焦点在哪儿。**
  之前 5 个页签一个都不在 Tab 链上（导航控件默认不可聚焦，也没有键盘事件），切页只能靠鼠标；
  现在它们都在链上，空格/回车就能翻到那一页，并画一圈蓝色描边告诉你焦点停在哪
  ——页签是自行绘制的，聚焦本身一个像素都不变，键盘用户原来是盲操作。

- **翻到别的页面不用再数着按 Tab。**
  实测在设置页里走到左侧页签要按 15 次 Tab（体检页 1 次、历史页 2 次、帮助页 3 次、首页搜索框 5 次），
  而这条链是单进单出的循环，没法给每一页都把页签提到最前面。所以改成给"切页"这个动作一条
  不依赖焦点位置的路：**Ctrl+1 ~ Ctrl+5** 直接跳到第 1~5 页，**Ctrl+Tab / Ctrl+Shift+Tab** 前后翻并绕回。
  加这几个键之前实测它们全是空的（不改页、不挪焦点、Ctrl+1 也不会往搜索框里插字符）。
  帮助页新增「不用鼠标也能操作」一节，把键盘路线和悬浮条/托盘的鼠标手势都写清了。

## 顺带

- 悬浮速率条进了真实像素闸门：它是半透明自绘窗口（桌面会透进来），文字对比度按**合成后的像素**算——
  实测白字对深/中灰/白桌面 15.69 / 11.53 / 9.64:1，全部过 WCAG AA；同时钉住"最长速率串必须整个画在胶囊里"
  （自绘没有省略号，越界就是数字被裁掉半截）。它的 tooltip 也补齐了操作说明（双击打开、拖动换位置、右键锁定/退出）。
- 提醒条在极限窄窗口（456 宽）里从 433px 收到 419px：原本用来扣"图标+边距+关闭按钮"的 154px
  是凑出来的数，实测那一圈是 167px，所以第一轮折行总能差一点点；现在第一轮按库给的常数几何估、
  之后按上一次量到的真实那一圈重算。

- 对比度闸门自己也修了一次（不影响界面，影响"以后这类问题还能不能被看见"）：它原先其实是被
  本机真实连接喂着跑的（排行榜里量到过 16 行「FlClash 内核」），而且会把**滚出视口**的标签
  当成"与背景同色的隐形文字"——那行文字在屏幕外，一个像素都没画，量到的是它上方那块卡片底色。
  现在测试建完窗口就停采集线程，并且只量完整落在视口里的标签；这道过滤还被写成"删掉它闸门必须红"。

## 质量闸门

- 新增两道永久验收：① 悬浮速率条闸门（合成底对比度 + 最长串不越界 + 操作可发现性）；
  ② 键盘闸门 11 步（初始焦点落在哪儿、Tab 链可达哪些控件、表格不困住 Tab、页签空格翻页、
  描边真画出来了、Ctrl 切页从任意焦点都翻对且左侧高亮跟上、关掉快捷键就翻不动）。
  键盘闸门必须真 `show()` 窗口——Qt 只给可见窗口设焦点，在隐藏窗口上量到的焦点链是假的
  （这一版能结案"标题栏残留子件偷走 Tab"这条旧怀疑，就是因为换了量法）。
- 全量回归 28 套件全绿（12 个数据/进程 + 16 个渲染），并覆盖 offscreen 与真实 Windows 两个平台。

## 下载与运行

- 解压后运行 `TrafficBoard/TrafficBoard.exe`（绿色目录，无需安装；`_internal` 必须和 exe 放在一起）。
- 数据落在 `%LOCALAPPDATA%\TrafficBoard\`，卸载就是删掉整个目录。
- 需要管理员权限才能看到全部进程的代理连接；不装代理也能用（退化成整机进程速率）。
- 压缩包 SHA256：`11586f360c36f7c9ff1ca141a55fc1002abbb2c5264934b8fbb87c02fc7b0741`

## 已知边界

- 界面固定深色主题：Windows 处于浅色模式时不会跟着变浅（跟着变会让 71 处文字里 48 处与背景同色，
  字还在但看不见），要开浅色得先做全局调色板引导 + 把界面里三十来处写死的深色收进调色板模块。
- 哪个软件直连用了多少，Windows 本身不提供数据，只有经过代理的流量有精确数字。
- 键盘页签仍排在页内控件之后：首页从搜索框按 5 次 Tab 到第一个页签，设置页要 15 次（数法：起点=该页第一个可聚焦控件，按真 Tab 逐跳量）。链是单进单出的循环，重排这一跳会把别的页序拆了东墙补西墙，所以「快速切页」交给 Ctrl+1~5 / Ctrl+Tab。
