# Traffic Board v1.6.6

这一版磨三件事：设置页不再只能用鼠标、搜索真正同时搜「软件」和「网站/IP」、
历史数据能导出成 Excel 能直接打开的 CSV。采集能力与数据口径和 v1.6.5 完全一致，没有新增统计。

## 设置页：键盘能走完全程

- **六个开关都能 Tab 到、空格/回车拨。** 之前开关的焦点策略是「不可聚焦」，
  键盘用户看得到、摸不着；硬按空格也拨不动。
- **聚焦时画一圈蓝色描边**，圈住开关本体和它的说明文字——开关控件被布局拉满整行，
  圈整行会像选中了一整张卡片。
- **开关拨动后说明文字不再变成 `On` / `Off`。** 之前文字会被开关状态覆盖，
  「固定图层（始终置顶）」这类说明拨一下就没了。
- **Esc 从设置页回到流量首页**，页内新增一行键盘提示；滚动区和滚动条退出 Tab 链，
  不会再出现「按了 Tab 却停在滚动条上」。
- 顺手修掉：给开关补上焦点后，最长的「固定图层」说明把设置页顶出了 9 像素横向滚动条；
  文案收短、解释挪进卡片说明后，456 宽的极限窗口仍不需要横向拖动。

## 搜索：一套命中口径，键盘一路到底

- **软件名和连接目标（域名 / IP:端口）用同一套判定。** 搜软件名给出它的全部连接；
  搜 IP 只给出命中的连接，排行副行写「匹配 N 条 · 共 M 条」，明细标题写「匹配 N / 共 M 条」，
  三个数字来自同一处计算，不再互相对不上。
- **选中的软件被搜索过滤掉时自动跳到第一条结果**；无结果时保留原选中，
  清空搜索框就回到原来的软件和明细。
- **Esc 清空搜索、Ctrl+F 从任意页回到首页并聚焦搜索框（全选已有内容）、
  回车选中第一条并把焦点送进右侧明细**，接着就能用 ↑/↓ 看连接。
- 空态分三种说清：全局无结果、进程已退出、进程在但没有可见连接。

## 历史页：数据能带走

- **新增「导出 CSV」**：把当前范围（最近 24 小时 / 最近 7 天）的本机分钟流量与
  软件代理流量导出成表格，表头为「类型 / 时间 / 软件 / 上行字节 / 下行字节 / 连接数」。
- 文件带 UTF-8 BOM，Excel 双击打开中文表头与软件名不乱码；先写临时文件再替换，
  中途失败不会毁掉上一次导出的同名文件。
- 范围里没有记录时连保存对话框都不弹，只提示「每满 1 分钟记一条，先运行一会儿」；
  导出成功/失败都在窗口顶部给出提示并写明行数与路径（窗口收进托盘时退回托盘气泡）。
- 以 `= + - @` 开头的软件名会加 `'` 前缀，避免被 Excel 当公式执行。
- 空态文案跟着范围走，软件排行会说明「代理流量需要 Clash 在线」。
- 图表坐标轴的灰色文字提亮，深色主题下更容易读。

## 质量闸门

- 新增三道永久验收：设置页键盘（v176）、搜索口径与键盘闭环（v177）、
  历史导出（v178）。连同原有闸门，串行全量回归 34 套件全绿，覆盖真实 Windows 与离屏两个平台。
- 测试 runner 的退出码与真相绑定：子进程失败不会再被管道/编码问题伪装成全绿；
  渲染套件建完窗口就停采集线程，不再往用户真实的 30 天历史库里写测试数据。
- 发布脚本支持 dry-run：不取 token、不联网，先把发布说明占位符、zip 内容与 exe 版本核对一遍。

## 下载与运行

- 解压后运行 `TrafficBoard/TrafficBoard.exe`（绿色目录，无需安装；`_internal` 必须和 exe 放在一起）。
- 数据落在 `%LOCALAPPDATA%\TrafficBoard\`，卸载就是删掉整个目录。
- 需要管理员权限才能看到全部进程的代理连接；不装代理也能用（退化成整机进程速率）。
- 压缩包 SHA256：`6c3d34a94949f857e54a15d8a4b338fc839e84ce741ce9c6856c53d87f9fa238`

## 已知边界

- 界面固定深色主题：Windows 处于浅色模式时不会跟着变浅（跟着变会让大量文字与背景同色），
  要开浅色得先做全局调色板引导 + 把界面里写死的深色收进调色板模块。
- 哪个软件直连用了多少，Windows 本身不提供数据，只有经过代理的流量有精确数字。
- UDP 连接的远端地址 Windows 系统表不提供（系统限制），UDP 明细依赖 Clash 数据源。
- 未提权时部分系统进程的归属信息拿不全。
- 键盘页签仍排在页内控件之后：设置页控件多，走到左侧页签要按十几次 Tab；
  快速切页用 Ctrl+1 ~ Ctrl+5 或 Ctrl+Tab / Ctrl+Shift+Tab。
- 历史 CSV 只覆盖最近 24 小时与最近 7 天两个范围；30 天全量导出还没有入口。
