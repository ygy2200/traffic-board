# Traffic Board v1.6.4

这一版继续磨「看得见」：窄窗口里的设置项、提醒里的路径、深色下的状态文字。
采集能力与数据口径和 v1.6.2 / v1.6.3 完全一致，没有新增统计。

## 修掉的三件具体事

- **设置页在窄窗口里不再需要横向拖滚动条。**
  「月流量上限」那一行横向最小要 550px，而 456 宽窗口的视口只有 407px——
  由于横向滚动条默认不显示，用户看到的不是「要拖一下」，而是「重置日那个框根本不存在」。
  现在宽窗口保持一行，窄窗口自动把「重置日」挪到第二行，并与上一行的输入框左对齐；
  没有靠压窄输入框来凑宽度（数字 + GB 后缀 + 上下按钮挤成一团是另一回事）。

- **提醒里的路径 / URL / 版本号不再从单词中间劈开。**
  上一版为了「提醒不超窗」改成按真实字宽折行，但折行是逐字符试的：
  中文那样是对的（没有空格可找），代价是 ASCII 被殃及——
  `C:\Users\<用户名>\Downloads\traffic_detail_2026-10-30.csv` 会折成 `...\Download` + `s\traffic_...`，
  你照着抄进资源管理器就少一个 s；`.../tag/v1.6.3` 折成 `.../tag/v1.6.` + `3`，版本号断成两截。
  现在中文照旧逐字可断，连续 ASCII 是一整块，放不下才在 `/ \ - _ . : ; , ? & % =` 后面断，
  数字之间的点不算断点；实在断不开的长串（60 位哈希）仍然硬拆——不撑爆行优先于词完整性。

- **深色下「● Clash 未连接」那行状态文字更清楚了。**
  用真实渲染像素把五页所有可见文字量了一遍对比度，全部界面文字里只有一处低于 WCAG AA：
  就是这行 3.78:1（正文要求 4.5:1）。它偏偏是「代理没生效」的关键提示，不该比正文更含糊，
  现在 5.64:1；「● Clash 已连接」那行 6.00:1 一并钉住。

## 质量闸门（对你没直接影响，但决定以后会不会再退步）

- 新增两道永久验收：① 真实像素文字对比度闸门（五页逐屏滚动量 83 处文字，低于 WCAG AA 就红）；
  ② 提醒条折行闸门（9 步，钉住「放得下的词必须整块」「断点只能在分隔符后」「内容一字不丢」）。
  两道都跑在真实渲染平台上——离屏平台的 ASCII 字宽是假机的一倍多（同一条 URL 量出 840px vs 377px），
  用假宽度选出来的用例碰不到真问题。
- 全量回归 26 套件（12 个数据/进程 + 14 个渲染）全绿。

## 下载与运行

- 解压后运行 `TrafficBoard/TrafficBoard.exe`（绿色目录，无需安装；`_internal` 必须和 exe 放在一起）。
- 数据落在 `%LOCALAPPDATA%\TrafficBoard\`，卸载就是删掉整个目录。
- 需要管理员权限才能看到全部进程的代理连接；不装代理也能用（退化成整机进程速率）。
- 压缩包 SHA256：`6219b945fec181ae97bc260a2b9d4ab9e932b8417664adee05ca3cc8a2ab8d0a`

## 已知边界

- 界面固定深色主题：Windows 处于浅色模式时不会跟着变浅（跟着变会让 71 处文字里 48 处与背景同色，
  字还在但看不见），要开浅色得先做全局调色板引导，已排进后续。
- 悬浮速率条的文字对比度还没进闸门（它是自绘半透明窗口），下一轮补。
